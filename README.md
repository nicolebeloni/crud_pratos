# Sistema de Gerenciamento de Pratos

#### Sistema desenvolvido em PHP, MySQL, HTML e CSS para cadastro de usuários e gerenciamento de pratos de um restaurante.

## Tecnologias utilizadas

#### PHP
#### MySQL
#### HTML
#### CSS
#### XAMPP

## Como executar

#### Instalar o XAMPP.
#### Iniciar o Apache e o MySQL.
#### Colocar a pasta do projeto dentro da pasta `htdocs`.
#### Abrir o phpMyAdmin pelo endereço `http://localhost/phpmyadmin`.
#### Criar o banco de dados e importar o arquivo `banco.sql`.
#### Configurar a conexão com o banco no arquivo `conexao.php`.
#### Acessar o projeto pelo navegador usando `http://localhost/nome-do-projeto/`.
